## What can proceed without accounts or spending

The first meaningful production-quality test is a single Poly Haven **native USD** broadleaf asset in an isolated comparison, provided its actual files can be retrieved normally. Its species mismatch remains explicit. This tests whether authored bark/leaf materials, branching and LODs materially outperform the current prototype. It does not justify replacing all district oaks with jacarandas.

For exact live oak and credible palm species, the professional candidates above require a distinct licensed-asset decision. No freely downloadable, correctly identified Southern live-oak plus Sabal-palm pair with verified raw redistribution rights was established in this bounded review. For cars, no acquired/rendered photorealistic CC0 sedan/SUV/van set was established. These are concrete remaining asset gaps, not reasons to declare the procedural result complete.

[NVIDIA's current USD sample-pack catalog](https://docs.omniverse.nvidia.com/usd/latest/usd_content_samples/downloadable_packs.html) is another native-format source: its automotive configurator pack is listed at2GB, while automotive **materials** alone are21GB. The current page does not establish a named redistributable oak/palm/car subset or its per-asset rights. Do not download huge packs speculatively or interpret free project use as CC0 redistribution. Likewise, [Fab's Standard License](https://www.fab.com/eula) permits compatible-tool project use but prohibits standalone asset redistribution; [Quixel](https://quixel.com/license) directs new acquisitions to Fab rather than promising the old unrestricted free library.

Any acquired candidate must keep original bytes/license receipt, package all texture dependencies with relative paths, preserve meter scale and ground pivot, and retain existing district instance transforms. Check leaf alpha/double-sided normals, bark UV scale, wheel contact, glass/paint response and silhouette in the **same close sidewalk and MainStreet context cameras**. Rendering cost and three useful detail levels need actual measurement. None of these asset replacements validates tree positions, parking rights, collision clearance or current species inventory; those remain separate#9/#10 acceptance gates.
